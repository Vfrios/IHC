# EntrePausas — Protótipo 2 (primeira versão preservada)

Aplicação web estática, mobile-first, em HTML/CSS/JavaScript, sem backend e sem login.

## Executar

Abra `index.html` diretamente ou sirva a pasta com qualquer servidor estático.

## Build

Não há etapa de compilação. Esta própria pasta é o resultado final. Para a entrega, uma cópia idêntica é mantida em `prototipo2/`.

Os dados simulados e o progresso de configuração são persistidos no `localStorage` do navegador.
